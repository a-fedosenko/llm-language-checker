Measured language support

What each model can actually produce — measured, not claimed.

These are heuristic results, not proof. Small samples, so every tier carries a confidence interval and a borderline flag when the interval spans a boundary. unverified means our back-translator could not read the language — a limit of the instrument, not a verdict on the model. Tier is capability; availability is willingness — a model can write a language well and still refuse most requests for it. Results are comparable only within the same back-translator, judge and method version.

The content score is the measurement; the tier is shorthand for it. A deterministic check decides whether the model wrote the requested language and script at all — wrong script or wrong language means unusable, full stop, and that check is never handed to a language model, which missed 15 of 15 script mismatches it caught. Everything that clears it is graded by how much of the required content survived a round trip, and the three tiers are a lossy view of that one number, kept only because a TMS has to route on something.

Dialects and variants

Inheriting a tier is not the same as inheriting a claim. A tag like de-AT takes its tier from de, which says nothing about whether the model marks that variant. Where a family divides by script, the probe's own script check answers it for free; where it divides by country, a closed marker set is compared against the sibling variant's. Everything else is untested — a placeholder we count, not a claim we make. This measures variant marking, which is a proxy for dialectal competence, not the thing itself.
